# Viral post breakdown

## 1. Targets
Keep a `REFERENCE_ACCOUNTS.md` list per account. New accounts are added as candidates only, after the user approves. Look at the last 30 days of posts and reels in the browser. If login is needed, use the user's existing session — never handle passwords.

## 2. What counts as "did well"
- Reels: views ≥ 3× that account's median recent reel.
- Carousels: likes + comments + reposts ≥ 3× its median recent carousel (comments/reposts only if likes are hidden).
- Saves and watch time are not visible on other accounts — do not guess them. Mark and exclude ads, giveaways and sponsored posts.

## 3. Break each one down (one row each)
`account | link | format | metric (×median) | first screen / cover line | hook pattern | first 3s / first slide composition | shot or slide order | caption first line | why it worked (observed only) | what we can apply`
"Why it worked" must cite something observable, e.g. what commenters actually asked.

## 4. Feed it back
- Add new hook patterns to `HOOK_LIBRARY.md` as "candidate"; promote to "proven" only after 3+ of your own posts perform with it.
- Never copy someone's sentence or layout. Take intent → structure → how it applies to you.
