# Weekly topic scout (built for follows, not views)

The goal is a weekly reason to follow the account. Fill 7 slots per account (3–4 reels, 3–4 carousels).

## 1. Read first
- Your account rules file
- Last 7 days of performance (saves, shares, profile visits, follows)
- Topics already covered — skip anything covered in the last 4 weeks

## 2. Fixed weekly sources (fill in per account)
- Official releases / drops / announcements in your niche (official sites and accounts)
- Rankings or "rising" lists in your niche
- 2–3 reference accounts (to find gaps, not to copy)
- Recent community talk (last 30 days)

## 3. Score candidates (0–2 each, max 10)
| Criterion | 2 points | 0 points |
|---|---|---|
| Timeliness | Released/announced this week | Old news |
| Reason to follow | Makes people want the next episode (series) | One-off info |
| Official source | Official photos/video available | No source / rights unclear |
| Save & share value | Prices, sizes, dates, details worth revisiting | Opinion only |
| Gap | Reference accounts haven't covered it / you have a different angle | Already everywhere |
+1 for a topic type that performed well 3+ times recently.

## 4. Output table
7 slots by score: `day | format | topic | score | first-screen hook (short) | cover line | caption first line | official source | official account to tag`. Add one line per rejected candidate explaining why.

## 5. Feedback after 7 days
Log reach, saves, shares, profile visits and follows next to each score. Lower the weight of criteria that scored high but performed low — only after the same pattern shows up 3+ times.
